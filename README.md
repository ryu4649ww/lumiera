# 蒼天のリュミエラ ―七彩の風と霧の巨像―

ブラウザーで遊べる、オープンワールド・アクションRPGです。空に浮かぶ大陸リュミエラを、走って・跳んで・崖を登って・空を滑って・泳いで旅し、4人の仲間を入れ替えながら「元素」を掛け合わせて戦います。

**遊ぶ：https://ryu4649ww.github.io/lumiera/** （ログイン不要。PC・スマホ縦横どちらでも遊べます。進み具合はブラウザーに自動保存）

## 操作
| 動き | PC | スマホ |
|---|---|---|
| 移動 | WASD | 左下のスティック |
| 視点 | マウス（画面をクリックで固定）・ホイールで距離 | 画面の右側をなぞる |
| ダッシュ（押し続けで全力疾走） | Shift／右クリック | ⇒ |
| ジャンプ・空中でもう一度押すと滑空 | Space | ↑ |
| 通常攻撃（長押しで溜め攻撃） | 左クリック | 剣のボタン |
| 元素スキル（ソラは長押しで大渦） | E | 小さい元素のボタン |
| 元素爆発（エネルギーが満タンの時） | Q | 大きい元素のボタン |
| 仲間の交代 | 1〜4 | 右の顔 |
| 調べる・話す | F | 手のボタン |
| 地図（ワープ）／依頼／メニュー | M／J／Esc | 右上のボタン |
| 写真モード | P（メニューの設定からも） | メニュー → 設定 → 写真モード |

## 遊びの要素
- 仲間4人：ソラ（風・片手剣）、アカネ（炎・両手剣）、ミズハ（水・法器、回復）、ライカ（雷・弓）。
- 元素反応：蒸発・溶解・過負荷・感電・超電導・凍結・拡散。
- 本編（三つの風の祠と霧の巨像）、依頼5本、風の結晶40個、宝箱25個、ワープ地点6か所、昼と夜。
- v1.4「もっと遊べる大陸」：
  - 天気が移ろう（晴れ・くもり・雨・雷雨、雨上がりの虹）。雨の中では敵が濡れて、雷・氷の反応が起きやすくなる。
  - 蝶・小鳥・魚。小鳥は近づくと飛び立つ。
  - 素材（リンゴ・キノコ・ミント・蜂の巣・小魚）を拾い、焚き火や町の大鍋で料理。攻撃・防御・スタミナ・会心の効果がつく。
  - 元素の仕掛け6つ（炎の燭台・雷の柱・風車と上昇気流）を解くと宝箱。
  - 写真モード（時刻・天気・ポーズ・表情・枠を変えて撮影、画像を保存）。
  - 記録と実績22個（地域ごとの探索度、旅の記録）。
  - 難しさ（やさしい／ふつう／むずかしい）。はじめからの時に選び、設定でいつでも変えられる。
